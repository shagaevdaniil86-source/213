# ПР8 Ответы на вопросы

## 1. Какие инструменты графического редактора наиболее полезны для извлечения информации о размерах, цветах и шрифтах?

В Figma полезны панель свойств выделенного элемента, Auto Layout, сетки, стили текста и цвета, измерение расстояний с Alt/Option, Dev Mode при наличии доступа. В репозитории имеется SVG-макет для импорта и таблица его параметров.

## 2. Как правильно организовать структуру CSS-переменных на основе данных из макета?

Переменные группируются по назначению: текст, фон, акцент, шрифт, размеры, отступы. variables.css содержит --ink, --accent, --paper, --space, --container, --font. design-tokens.json фиксирует значения исходного макета.

## 3. Какие метрики из макета наиболее критичны для точной верстки (размеры, отступы, шрифты)?

Критичны ширина контейнера, высота шапки, соотношение колонок, интервалы между секциями и карточками, размеры заголовков и line-height. Здесь контейнер 1120px, шапка 80px, hero 520px, gap карточек 24px, h1 48px.

## 4. Как определить систему сетки, используемую в макете и перенести ее в CSS Grid или Flexbox?

Нужно определить количество колонок, ширину контейнера и gutter, затем перенести это в grid-template-columns и gap. Hero макета имеет две колонки с промежутком 48px, преимущества — три карточки с gap 24px.

## 5. Какие сложности возникают при переносе типографики из графического макета в веб-страницу?

Метрики шрифтов, доступность начертаний, переносы строк и сглаживание могут отличаться. Нужно использовать одинаковый шрифт и ширину текста, задавать line-height и проверить переносы. В нашем макете и странице используется Arial.

## 6. Как обрабатывать адаптивность, когда в макете представлен только десктопный вариант?

Определить приоритет блоков и момент, когда колонки перестают помещаться, затем перевести их в одну колонку, перенести меню и уменьшить заголовки через clamp. В работе перестройка задаётся до 768px.

## 7. Какие инструменты браузера помогают сравнивать сверстанную страницу с оригинальным макетом?

DevTools показывает размеры и box model, computed styles и сетку. Скриншоты одного viewport можно сравнить наложением. Сравнение имеет смысл при одинаковой ширине, масштабе и загруженных шрифтах.

## 8. Как правильно экспортировать изображения из графического редактора для веб-использования?

Для векторной иллюстрации удобен SVG, для фотографии — WebP/AVIF/JPEG, для прозрачной растровой графики — PNG/WebP. Нужно сохранять пропорции и задавать осмысленный alt. Использована собственная иллюстрация bike.svg.

## 9. Что делать, если в макете используются шрифты, которых нет в веб-доступе?

Проверить лицензию и возможность веб-подключения; если файл недоступен, выбрать близкий разрешённый шрифт и согласовать замену. Нельзя незаметно заменить шрифт и обещать полное соответствие. Наш макет использует веб-безопасный Arial.

## 10. Какие методологии помогают поддерживать соответствие между макетом и кодом при дальнейших изменениях?

Дизайн-токены, переиспользуемые компоненты, единая система отступов, именование классов и сравнение скриншотов помогают поддерживать соответствие. Изменения макета следует переносить в variables.css и компоненты согласованно.
