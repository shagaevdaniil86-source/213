# ПР15 React компоненты

Запускаемая лаборатория ВелоКруга: все компоненты и хуки из задания, примеры их использования и функциональные тесты. Классы используются для изучения жизненного цикла; новые функциональные компоненты используют hooks.

## Запуск

Нужен Node.js 22.12+ (или Node.js 24) и npm.

```bash
cd react-components
npm install
npm start
```

Откройте адрес, который выведет Vite (обычно `http://127.0.0.1:5173`). Исходный `index.html` нельзя запускать двойным щелчком: JSX требует сборщика.

```bash
npm test
npm run build
npm run preview
```

Вместо устаревшего генератора Create React App используется Vite. Требуемая структура `src/components` и имена `.js` сохранены, JSX обрабатывается в `vite.config.js`. Зафиксированные зависимости находятся в `package.json` и `pnpm-lock.yaml`. Для установки через pnpm: `pnpm install --frozen-lockfile`.

## Демонстрации

- Props, children, условный рендеринг и кнопки.
- Классовые счётчик, форма, выбор цвета, список задач и поиск.
- Секундомер, размер окна, загрузка при монтировании и изменении URL; кнопка размонтирования показывает очистку ресурсов.
- Счётчик и профиль с useState, три варианта useEffect.
- useLocalStorage с синхронизацией вкладок, useFetch с отменой запроса, тема через Context.
- Кнопка проверки отображения и отдельные автоматические тесты поведения.

Запросы читают учебный JSONPlaceholder API и требуют интернета. Тесты используют подменённые ответы и не зависят от внешней сети. Форма входа проверяет значения локально. В localStorage сохраняются только выбранная тема и заметка.
