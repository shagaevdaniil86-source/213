# ПР11 Ответы на вопросы

## 1. В чем разница между innerHTML и textContent и когда следует использовать каждый метод?

innerHTML разбирает строку как HTML и может создать опасную разметку из непроверенных данных. textContent вставляет обычный текст. В работе карточки, ошибки и данные пользователя создаются через createElement/textContent.

## 2. Как работает делегирование событий (event delegation) и какие преимущества оно дает при работе с динамическими элементами?

Один обработчик у контейнера получает всплывающие события дочерних элементов. По closest() определяется действие. Это уменьшает число обработчиков и работает с новыми элементами: кнопки удаления списка не требуют отдельной настройки.

## 3. Какие методы используются для поиска элементов в DOM и в чем разница между getElementById, querySelector и querySelectorAll?

getElementById ищет один уникальный ID. querySelector возвращает первое совпадение CSS-селектора. querySelectorAll возвращает статический NodeList всех совпадений. В работе ID применяются к целевым блокам, селекторы — к классам дочерних элементов.

## 4. Как предотвратить стандартное поведение элемента при обработке событий и когда это необходимо?

event.preventDefault() отменяет действие браузера, если событие cancelable: например, отправку формы или переход по ссылке. В работе submit формы обрабатывается локально без перезагрузки.

## 5. В чем разница между classList.add() и className для работы с CSS классами?

classList.add() добавляет токен класса, сохраняя остальные; className присваивает всю строку классов. classList.toggle() удобно для переключения .active-style. Для сложного набора классов classList обычно безопаснее.

## 6. Как создать новый элемент и добавить его в DOM несколькими способами? Какой способ наиболее эффективен?

createElement создаёт узел, append/appendChild добавляет в конец, prepend — в начало, before/after — рядом, insertBefore — перед узлом. Для набора элементов используется DocumentFragment, затем одна вставка в список.

## 7. Что такое всплытие событий (event bubbling) и как работает метод stopPropagation()?

Всплытие передаёт событие от target к предкам. stopPropagation() прекращает дальнейшее прохождение, но не отменяет стандартное действие и не блокирует другие обработчики того же узла. Для них существует stopImmediatePropagation().

## 8. Как получить данные из формы и в чем разница между методами сбора form data?

FormData собирает успешные именованные элементы формы, в том числе файлы и выбранные checkbox. Ручное чтение .value требует собрать каждое поле. Object.fromEntries удобно для уникальных имён, но повторные имена нужно читать getAll().

## 9. Какие события используются для обработки ввода данных и в чем разница между input, change и keyup?

input срабатывает при изменении значения; change — при подтверждении изменения и для select/checkbox; keyup — при отпускании клавиши и не охватывает все способы ввода, например вставку мышью. Отображение заметки использует input.

## 10. Как оптимизировать производительность при частых манипуляциях с DOM?

Группировать вставки, избегать чередования чтения layout и записи стилей, использовать делегирование и обновлять только нужные узлы. Для анимации применять transform/opacity и requestAnimationFrame. DocumentFragment используется в createList.
