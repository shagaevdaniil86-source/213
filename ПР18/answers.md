# Практическая работа №18 — ответы на вопросы

**Тема:** React: маршрутизация

### 1. В чём разница между Link и NavLink в React Router?
`Link` создаёт ссылку для перехода между маршрутами без полной перезагрузки страницы. `NavLink` делает то же самое, но дополнительно сообщает, активна ли ссылка, через `isActive`; это удобно для подсветки текущего раздела меню.

### 2. Как получить параметры из URL в компоненте?
Использовать хук `useParams()`. Например, для маршрута `/products/:id` код `const { id } = useParams();` возвращает значение параметра `id` как строку.

### 3. Что такое программная навигация и как её реализовать?
Это переход на другую страницу по результату действия в коде, а не после нажатия на ссылку. Хук `useNavigate()` возвращает функцию `navigate`: например, `navigate('/products')` или `navigate(-1)`.

### 4. Как передать данные между маршрутами?
Можно использовать параметры URL (`/products/:id`), строку запроса, общее состояние приложения или свойство `state` у `navigate` / `Link`. Пример: `navigate('/contact/success', { state: { message: 'Успех!' } })`. На целевом маршруте данные читаются через `useLocation().state`. Эти данные не следует считать постоянным хранилищем.

### 5. Что делает компонент Routes?
`Routes` анализирует текущий URL, выбирает наиболее подходящий вложенный `Route` и отображает указанный в его `element` React-компонент.

### 6. Как создать защищённый маршрут?
Создать компонент-обёртку, проверяющий авторизацию. Если пользователь вошёл в систему — вернуть `<Outlet />` (или дочерний компонент); иначе — `<Navigate to="/login" replace />`. Проверку прав также обязательно выполнять на сервере: ограничение маршрутов в интерфейсе само по себе не защищает данные.

### 7. В чём разница между useNavigate и redirect?
`useNavigate` — хук для навигации из React-компонента, например по нажатию кнопки или после отправки формы. `redirect()` применяется прежде всего в `loader` и `action` маршрутизаторов с API данных, где перенаправление выполняется на уровне маршрута, до обычного рендера компонента.
