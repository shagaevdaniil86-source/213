# Практическая работа №18 — React: маршрутизация

**Цель:** освоить React Router, навигацию, параметры URL и программные переходы.

## Выполненные задания
1. Базовая маршрутизация: главная, о нас, товары, контакты и страница 404.
2. Динамический маршрут `/products/:id`, карточки товаров и фильтрация по категории.
3. Контактная форма, `useNavigate` и передача данных на страницу подтверждения через `location.state`.
4. Ответы на вопросы — файл [answers.md](./answers.md).

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite в терминале (обычно `http://localhost:5173`).
