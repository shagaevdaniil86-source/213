# ПР6 Ответы на вопросы

## 1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?

meta name="viewport" content="width=device-width, initial-scale=1" связывает CSS viewport с шириной устройства. Без него мобильный браузер может использовать широкий виртуальный экран и уменьшать страницу целиком.

## 2. Какие основные подходы к созданию адаптивных макетов вы использовали в работе (Fluid, Adaptive, Responsive)?

Использован Responsive: гибкая ширина контейнера и изображений сочетается с медиа-запросами. Fluid проявляется в процентах и clamp; Adaptive — в дискретных перестройках числа колонок и меню.

## 3. Как работает Mobile First подход и в чем его преимущества перед Desktop First?

Mobile First начинает с простого мобильного макета и добавляет возможности через min-width. В работе базовая сетка одноколоночная; более широкие экраны получают две и три колонки. Это облегчает приоритизацию содержания.

## 4. Какие единицы измерения наиболее предпочтительны для адаптивной верстки и почему (%, rem, em, vw/vh)?

% подходит для доли родительского блока, rem — для размеров относительно корневого шрифта, em — относительно шрифта элемента, vw/vh — относительно viewport. В работе rem используется для отступов, % для контейнера, vw внутри ограниченного clamp.

## 5. Как функция clamp() помогает создавать адаптивную типографику?

clamp(min,preferred,max) ограничивает текучий размер снизу и сверху. Заголовок clamp(2rem,5vw,4rem) растёт с экраном, но остаётся читаемым на малом и не становится чрезмерным на большом.

## 6. Какие основные брейкпоинты вы использовали и как определили эти значения?

481px переводит карточки в две колонки, 769px показывает десктопное меню, 1025px — три колонки и две колонки основного контента. Значения выбраны по моментам, когда содержание начинает помещаться; они покрывают диапазоны из задания.

## 7. Как медиа-запросы @media помогают создавать адаптивные стили? Приведите пример синтаксиса.

@media (min-width:769px) {.nav-toggle {display:none}} применяется при viewport не уже 769px. Медиа-запросы изменяют оформление при выполнении условия, не меняя HTML.

## 8. В чем разница между max-width и min-width в медиа-запросах и когда использовать каждый?

min-width действует начиная с порога и удобен для Mobile First. max-width действует до порога и удобен для локального упрощения широкого макета. В работе оба используются для разных задач.

## 9. Как сделать изображения адаптивными и какие CSS-свойства для этого используются?

img {max-width:100%;height:auto} сохраняет пропорции и не допускает превышения контейнера. Атрибуты width/height резервируют пропорции. Для разных растровых размеров можно добавить srcset и sizes, для другой композиции — picture.

## 10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?

Режим Device Toolbar проверяет размеры viewport, масштаб и эмуляцию устройства. Вкладки Layout и Computed помогают найти переполнение; консоль — ошибки меню. Проверять нужно также клавиатуру и реальные устройства, а не только эмуляцию.
